# Triage 标签

工程技能使用五个标准 triage 角色。本仓库采用同名标签。

| 工程技能中的角色  | 本仓库标签        | 含义                         |
| ----------------- | ----------------- | ---------------------------- |
| `needs-triage`    | `needs-triage`    | 维护者需要评估该 issue       |
| `needs-info`      | `needs-info`      | 等待报告者补充信息           |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可交给智能体执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实现                 |
| `wontfix`         | `wontfix`         | 不予处理                     |

技能提到某个 triage 角色时，使用表中对应的本仓库标签字符串。
