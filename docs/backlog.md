# 项目待办

本文记录维护者在探索项目时想到、并明确要求记下的想法，供以后回顾和讨论。
只有明确要求记录时才新增条目；记录不代表已决定实施，也不构成实施授权。

## 约定

- 开始实施某条目时确认范围并更新状态；交付时更新状态、更新日期和关联 PR。
  已完成条目从本文移除，历史记录通过 Git 追溯。
- 优先级：P0 阻塞使用或发布；P1 重要候选；P2 后续安排；P3 探索。
- 状态：待规划、待实施、进行中、已完成、暂缓。
- 工作量：S 局部修改；M 跨模块修改；L 需要先拆解。工作量不代表工期承诺。
- 日期使用 `YYYY-MM-DD`。ID 按顺序分配，不复用；下一个新条目使用 `BL-001`。
  元数据以总览表为准。

## 总览

当前无已登记条目。模板项目的待办不继承为本项目的任务；已确认的业务边界见[架构说明](architecture.md)。
