# 目标范围是元数据，目标内容是同步内容

多机使用要求新增机器时只调整目标适用范围，而不重新收录内容；同时，目标内容的变化必须经过三方比较，
不能在范围操作中顺带覆盖其他机器或平台的字段。`capture`、`target update` 与 `sync`/`resolve` 因此分工明确：

- `capture` 只负责首次收录，从本机值建立远端目标和初始同步基线，不提供更新入口。
- `target update` 只重写目标的机器范围元数据，保留单位、秘密版本、recipient 和数据文件。
- 目标内容的增删改继续通过 `sync` 与 `resolve` 完成；`sync` 遇冲突时不写入任何一侧。

这样范围调整不会触碰内容，避免 capture 更新语义误删其他平台字段，也让内容变化保留三方比较和显式冲突解决。
代价是扩大范围后仍需在目标机器执行 `sync` 才能取得内容；已移除目标的本机基线由全量 `sync` 清理，
远端不新增删除标记或代次字段，`remove` 后立即重新收录的窗口仍是已知限制。
