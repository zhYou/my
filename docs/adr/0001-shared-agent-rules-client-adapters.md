# 共享智能体规则，客户端配置独立适配

项目需要同时支持 Codex 与 OpenCode 开发，但两个客户端的 MCP、权限、技能发现和命令压缩机制不同。
仓库以根目录 `AGENTS.md` 和共享开发文档定义唯一行为规则，Codex 与 OpenCode 只通过各自的客户端适配层
配置本机启动、权限和工具接入；不追求 RTK、个人技能或权限实现的逐项对等。

这一边界避免复制和维护两套流程规则，同时允许客户端使用自身原生机制。代价是 Codex 专属 RTK 与
OpenCode 权限会分别演进，跨客户端新增能力必须明确它属于共享规则还是单个客户端适配层。
